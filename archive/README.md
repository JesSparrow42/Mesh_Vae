# Historical code

This folder keeps earlier implementations, experiments, and notebooks for reference. The active implementation lives in [`meshvae/`](../meshvae/), [`body_measurements/`](../body_measurements/), and [`paper_analysis/`](../paper_analysis/), with the current Python entry points in the repository root.

| Folder | Contents |
| --- | --- |
| `Old_Code/` | An earlier refactored MeshVAE snapshot, including its original guides. |
| `MQVAE/` | Earlier standalone MeshVAE scripts and a visualization notebook. |
| `Work/` | Experimental models, helper scripts, notebooks, and historical requirements files. |
| `meshvae_old_versions/` | Previous versions of selected package modules. |
| `original_github/` | The older `mesh_conv_model.py` retained from the original GitHub repository. |

The internal layouts of the snapshots are preserved. Their commands may depend on the environments, datasets, and paths used when they were written; update those settings before running an archived workflow.

Use the [main README](../README.md) and current guides for active workflows. Keep datasets and trained checkpoints outside Git.
