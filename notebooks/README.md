# Analysis notebooks

`tsne_plaque_latent.ipynb` visualizes latent embeddings from a trained plaque-volume
model. Configure the repository, data, split, and checkpoint paths in its first
code cell for the machine where it will run.

The paper-analysis notebooks stay with their related Python modules in
[`paper_analysis/`](../paper_analysis/README.md). Earlier exploratory notebooks are
preserved in [`archive/`](../archive/README.md).

Clear saved cell outputs before committing notebooks so generated datasets and
large visualizations are not embedded in the repository.
